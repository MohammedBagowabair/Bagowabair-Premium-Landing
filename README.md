# Bagowabair Premium Landing

A single-page site for Mohammed Bagowabair, an independent software developer. It is static HTML, CSS, and JavaScript, with GSAP stored in the repository. There is no build step.

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173/`.

The page is meant to be published from the repository root on GitHub Pages, at `https://mohammedbagowabair.github.io/Bagowabair-Premium-Landing/`. Links to images, CSS, and scripts are relative so that address works.

Design notes from the reference study are in `DESIGN-NOTES.md`.
